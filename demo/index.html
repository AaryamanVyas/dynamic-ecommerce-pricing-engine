A FIVE-MINUTE CLASSROOM WALKTHROUGH
Present the product, then prove the architecture
  1. Compare a grocery. Choose Nutella 400 g. Show barcode, store names, prices, observation dates and a minimum-floor recommendation.
  2. Inspect the real deployment. Show your account, ap-south-1 region, CloudFormation stack and resource counts. Open the discovered AWS console links.
  3. Explain security and asynchronous events. Show IAM route checks, the blocked unsigned request and native API Gateway → EventBridge integration. Explain retries and the SQS failure queue.
  4. Run a cloud check. Point out the EventBridge ID, the matching stored observation and SES acceptance or cooldown. Open collector/evaluator CloudWatch logs and search that observation ID.
  5. Show the vendor email and trend. Inbox delivery is separate from SES acceptance. Explain that historical grocery observations have real dates; the estimate is anchored to the latest record of one store.
Useful review points: serverless compute, pay-per-request storage, event routing, least-privilege roles, retries, TTL, logs and failure monitoring. eBay integration remains prepared; the grocery demo uses the public Open Prices API. Historical data is not presented as a live shelf-price guarantee.
